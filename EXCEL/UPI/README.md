
# 📊 UPI Transaction Dashboard in Excel

## 📌 Project Overview

This project presents an **interactive UPI Transaction Dashboard** built entirely in **Microsoft Excel**. The dashboard provides meaningful insights into UPI transactions by analyzing customer behavior, transaction performance, payment trends, and regional activity.

Using Excel features such as **Pivot Tables, Pivot Charts, Slicers, Timelines, and Conditional Formatting**, this dashboard transforms raw transaction data into an easy-to-understand business intelligence report.

---

## 🎯 Project Objectives

* Analyze UPI transaction trends.
* Monitor transaction success and failure rates.
* Identify top-performing UPI applications.
* Understand customer demographics.
* Analyze transaction amounts across states and cities.
* Track merchant category performance.
* Provide interactive filtering for better decision-making.
